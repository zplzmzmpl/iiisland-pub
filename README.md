## 抬眼看歌词，伸手控音乐

不用来回切换播放器。iiisland 将封面、歌曲信息、播放控制和歌词放在屏幕顶部：收起时轻巧陪伴，悬停或点击即可展开。

- **跟上你正在听的。** 支持 Apple Music、Spotify、QQ 音乐与网易云音乐；自动跟随最近开始播放的来源，也可固定常用播放器。
- **一句歌词，两种位置。** 收起时，歌词贴在灵动岛左侧；展开时，回到播放面板。四项胶囊自动隐藏默认关闭，可按需开启；岛内歌词默认开启，随灵动岛开关同步切换，仍可单独调整。
- **自己校准歌词。** 在「歌词 → 时间同步」输入数值、按 100 毫秒微调或重置，统一在设置窗口内完成。
- **适合你的屏幕。** 分别调整收起与展开的宽高，支持有刘海与无刘海屏幕布局。
- **两种外观。** 经典黑融入屏幕顶部；macOS 26 上可选择原生液态玻璃。日间与夜间模式可以手动切换并记忆。
- **随播放器启动。** 开启后，启动支持的播放器即可打开 iiisland。

## 播放器支持

| 播放器 | 歌曲、封面与歌词 | 播放、切歌与进度 | 音量、随机与循环 |
| --- | --- | --- | --- |
| Apple Music | 支持 | 支持 | 支持 |
| Spotify | 支持 | 支持 | 支持 |
| QQ 音乐 | 支持 | 取决于系统媒体焦点与可用能力 | 暂不支持 |
| 网易云音乐 | 支持 | 取决于系统媒体焦点与可用能力 | 暂不支持 |

歌词来自在线服务、可用的内嵌歌词与本地缓存；是否能取得歌词及同步精度取决于歌曲和来源。QQ 音乐与网易云音乐首次使用时，请先在播放器中播放歌曲。

也可在「播放器 → 接入其他媒体应用」中开启浏览器、视频播放器等系统媒体来源，默认关闭。应用或网页需发布系统媒体会话；播放中的音乐优先，其他媒体不查询歌词，控制能力随来源与系统版本而异。

## 下载与安装

当前版本：**0.8.27 · build 36**，安装包更新于 **2026-11-07**。

要求 **Apple Silicon（arm64）Mac、macOS 14 或更高版本**。当前不提供 Intel 安装包；原生液态玻璃需要 macOS 26。

1. 在 [Releases](https://github.com/zplzmzmpl/iiisland-pub/releases/latest) 下载 `iiisland-0.8.27-arm64.dmg`。
2. 打开 DMG，将 `iiisland.app` 拖入旁边的 `Applications` 文件夹。
3. 从“应用程序”启动 iiisland，并在音乐播放器中播放一首歌。

更新时，先退出旧版本，再替换应用。

**首次打开：** 当前安装包使用 ad-hoc 本地签名，未经 Developer ID 签名或 Apple 公证，macOS 可能阻止首次打开。首次连接 Apple Music 或 Spotify 时，系统可能请求自动化授权；QQ 音乐与网易云音乐的媒体读取不需要辅助功能或屏幕录制权限。

### 校验安装包

同时下载 DMG 与同名 `.sha256` 文件，在下载目录运行：

```sh
shasum -a 256 -c iiisland-0.8.27-arm64.dmg.sha256
```

本次安装包 SHA-256：

```text
d4fe9e1dbc9faaaa00f3f43b435bc885598abd832f02490d4c6a54a09ae885b7
```

## 0.8.27 有什么更新

- 菜单只保留「设置」「退出」；歌词偏移、日夜模式与字体颜色都在同一设置窗口调整。
- 字体颜色改为页内常用色块和 HEX 输入，保留任意 RGB 颜色；切换全屏、桌面和外观时保持所选颜色。
- 岛内歌词默认开启，随灵动岛关闭／重新开启同步关闭／开启。
- 鼠标经过、暂停、截图和打开应用菜单四项自动隐藏默认均关闭，可在设置中按需开启；保留已有用户选择。
- 迁移至 Swift 6，明确歌词加载与缓存的并发边界，并改进后台事件共享、取消和资源生命周期。

详见 [0.8.27 正式发布说明](https://github.com/zplzmzmpl/iiisland-pub/releases/tag/v0.8.27)。

### 已发布的 0.8.24

- 胶囊背景固定为通透液态玻璃，文字只提供「浅色」「深色」两项；macOS 26 以下使用磨砂玻璃。
- 深色字体仅在当前显示器进入独立全屏空间时临时变浅，退出恢复；普通桌面内的铺满、最大化或新增普通桌面不触发。固定浅色始终保持浅色，不启动检测。
- 透明度支持滑块及手动输入 0%–100%，可保留一位小数。0% 保留完整玻璃，100% 隐去背景，文字不变；默认浅色字体、4% 透明度。
- 移除自动字体模式及屏幕采样，不申请屏幕录制或辅助功能权限。设置卡片保持单行完整；展开布局只保留有刘海、无刘海，修正刘海示意。
- 空闲歌名改为「is that u ?」。通过 1,734 项胶囊、334 项整应用宿主及全屏生命周期检查，包含 60 次设置窗口释放。

全屏联动依赖非公开系统空间接口，读取失败保留所选深色字体；已在本机原生全屏空间验证，其他系统版本及多显示器组合仍需复验。

详见 [0.8.24 版本发布说明](https://github.com/zplzmzmpl/iiisland-pub/releases/tag/v0.8.24)。

### 已发布的 0.8.23

- 「歌词 → 胶囊背景」新增「深底浅字」与「浅底深字」两种固定配色，独立于应用日间／夜间模式。
- 可调节 0%–100% 背景透明度，支持实时预览和恢复默认。0% 为不透明，100% 为背景与描边完全透明，文字强度不受影响。
- 配色与透明度在重启后保留；切换外观不重建可见歌词窗口、不打断切句动画，也不重新搜索歌词。
- 1,549 项胶囊检查、332 项完整应用宿主检查通过，包含 60 次实际设置窗口释放；原生界面另行验证了配色、透明度、重启保留与恢复默认。

详见 [0.8.23 版本发布说明](https://github.com/zplzmzmpl/iiisland-pub/releases/tag/v0.8.23)。

### 已发布的 0.8.22

- 修复灵动岛悬停偶发不能展开、快速移动时控件旧高亮残留，以及灵动岛和状态栏菜单高亮随设置开关变迟钝的问题。
- 打开菜单时等待实际激活，取消菜单后按需返回原应用；从菜单打开设置时设置正常获得焦点。
- 缩小播放时的界面刷新范围，移除无效动画；快速切歌时串行解码封面并丢弃过期请求，减少额外工作。
- 优化设置关闭后的资源释放，将播放器启动偏好同步移至后台，连续切换时保留最终选择。
- 20 组回归脚本通过，含 332 项完整应用宿主检查、60 次实际设置窗口释放及 333 项原生悬停/菜单检查；优化构建已由用户确认运行正常。

首次打开设置会加载系统控件与进程缓存，关闭后内存不必回到此前从未打开设置时的数值；本版不承诺固定的内存降幅。歌词偏移、自动显隐、播放器与系统媒体支持继续保留。

截图隐藏检测 ⌘⇧ 组合键与系统截图工具；其他 ⌘⇧ 快捷键也会暂时隐藏，极快按键、重映射快捷键及第三方截图／录屏可能无法隐藏。浏览器和视频播放器兼容性仍随系统媒体会话能力而异。

详见 [版本发布说明](https://github.com/zplzmzmpl/iiisland-pub/releases/tag/v0.8.22)。
