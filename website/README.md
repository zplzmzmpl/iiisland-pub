# iiisland 宣传网页

官网：https://iiisland.pages.dev。通过 Cloudflare Pages 的 Git 连接自动部署。

页面使用纯静态 HTML/CSS/JavaScript，无需安装依赖或构建。公开网站源码在本仓库的 `website/` 中维护，应用源码仍保留在私有仓库。

页面使用暖纸 #f5efea 与深墨蓝 #122e8a 的双色撞色体系：蓝色导航、屏幕、尺寸区、播放器区和下载区与纸色标题、歌词、FAQ 区交替成块，蓝色下载区保留为剖面图体系中的蓝色发行章。当前视觉方向为「屏幕剖面图」：暖白绘图纸、墨线、蓝铅笔尺寸标注、图签栏与钉住的图标参考图；灵动岛是图上唯一会动、可操作的实体。设计令牌与组件规则见根目录 `DESIGN.md`。播放控制与歌词共享状态。“调成你的样子”使用独立的尺寸动效：进入视野后自动往返循环播放（单程 4 秒），说明应用中收起与展开的宽高可独立调整。该区域不包含尺寸滑块、外观／屏幕选项、展开／收起或日夜操作，不克隆播放组件，不使用 JavaScript 测量或缩放。

尺寸示意使用固定 1:1 布局，内层轮廓的宽度、高度与底部圆角在 280 × 44 / 18px 与 440 × 266 / 28px 之间过渡；展开态内容在收缩前淡出，收起态内容在完全收起后出现，中间帧不会露出面板文字。封面与歌词放在同一裁切轮廓内，展开空间足够后再淡入，避免过渡帧露出岛体。

## 本地预览

直接在浏览器打开 `index.html`，或用静态文件服务器将 `website/` 作为网站根目录。网页演示不播放音频或连接实际播放器；曲目与歌词为原创演示内容，封面使用应用图标。尺寸示意在关闭 JavaScript 或启用系统“减少动态效果”时保持静态展开，说明文字始终可读；尺寸标注按 1:1 显示收起 280 × 44 与展开 440 × 266。

## Cloudflare Git 部署

Cloudflare Pages 仅保留正式项目 `iiisland`，连接 GitHub 仓库 `zplzmzmpl/iiisland-pub`，使用以下设置：

| 设置 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 框架 | None |
| 根目录 | 仓库根目录 |
| 构建命令 | 留空 |
| 构建输出目录 | `website` |

提交并推送 `website/` 中的更新后，Cloudflare 自动部署，无需手动上传文件夹。可将构建监视路径限定为 `website/**`，避免仅更新宣传 README 时触发部署。

网站输出包含 `index.html`、`style.css`、`script.js`、`404.html`、`assets/app-icon.png`；本目录 README 是维护文档。临时 TXT 验证文件只在本地保留，由 `.gitignore` 排除，不提交、不部署。

关闭 JavaScript 后仍可阅读说明、FAQ 和下载链接；遵循系统减少动态效果。无外部字体、统计脚本或第三方运行时。

## 正式域名

唯一正式地址为 `https://iiisland.pages.dev`。旧 Pages 域名已停用，不再提供回迁入口。GitHub 仓库名仍为 `iiisland-pub`，与正式 Pages 项目名不同。

曾缓存历史 301 的浏览器需要清除相关网站缓存，或先使用 `https://iiisland.pages.dev/?v=20261025` 绕过旧缓存。当前正式站不设置域名跳转。
