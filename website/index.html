安装前，了解这些

查看项目说明
我的 Mac 可以安装吗？

支持 Apple Silicon（M 系列芯片），需要 macOS 14 或更高版本。当前未提供 Intel 安装包。

怎样安装和更新？

从 GitHub Releases 下载 DMG，打开后将 iiisland.app 拖入 Applications，再从“应用程序”启动。更新前先退出旧版本，再替换应用。

macOS 提示无法打开？

当前安装包使用 ad-hoc 本地签名，未经 Developer ID 签名或 Apple 公证，macOS 可能阻止首次打开。发布页提供 SHA-256 文件，可用于校验下载内容。

歌词从哪里来？

来自在线歌词服务、可用的内嵌歌词与本地缓存。是否能获取歌词、是否同步准确，取决于歌曲与来源。两处显示共用一次加载和同一条时间轴。

可以随播放器启动吗？

可以。在应用的播放器设置中开启“随播放器启动”。自动模式响应四款支持的播放器；手动模式只响应选定来源。
